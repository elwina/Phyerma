# 气压

| 项 | 值 |
|---|---|
| 实验类型名 | `pressure` |
| Android type | `Sensor.TYPE_PRESSURE`（值为 6） |
| SI 单位 | hPa（与 mbar 相同） |
| 分量 | 标量 |
| 众包库字段 | `p` 有/无；`prat` Hz；`pn` 芯片名。无均值/σ |
| 接入状态 | 仅对照，未改实验 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

海平面标准大气约 1013.25 hPa。室内一般 980–1040。  
高度粗估：\(\Delta h \approx \Delta P / 0.12\) 米（每 hPa 约 8 m，近地面更常用 12 Pa/m）。电梯实验靠这个。

## 2. 代码路径

先 `getDefaultSensor(TYPE_PRESSURE)`。没有则扫 `TYPE_DEVICE_PRIVATE_BASE` 以上、名字含 `pressure` 的项，并标 `vendorSensor`（会警告）。

## 3. 内置实验

`pressure.phyphox`，`elevator.phyphox`（1 Hz 平均，配合线性加速度）。

## 4. 已知坑

- 大量中低端国产机没有气压计，实验直接不可用。
- vendor 私有压力可能是气态检测/血压类，不是大气压。
- 单位若报 Pa，数值会在 ~1e5，比 hPa 大 100 倍。
- 空调/开门会造成 Pa 级抖动，电梯实验要平均。

## 5. 现行做法

实验原样。库只提供有无、Hz、芯片名。本机页对照「库说有没有」和「HAL 现在有没有」。

## 6. 候选规则（草案）

读数长期在 9e4–1.1e5：提示「疑似 Pa，÷100」。读数在 10–20：提示「疑似 psi 或 kPa，勿自动换」。没有传感器就保持实验不可用，不要用 GPS 高度顶替，除非单独做实验。

## 7. 待测机型与问题

- [ ] 统计目标机型有气压计的比例
- [ ] 有气压的机：室内是否 ~1000 hPa
- [ ] vendor 回退是否曾误匹配
