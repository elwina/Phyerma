# 陀螺仪

| 项 | 值 |
|---|---|
| 实验类型名 | `gyroscope` |
| Android type | `Sensor.TYPE_GYROSCOPE`（值为 4） |
| SI 单位 | rad/s |
| 分量 | x y z + abs |
| 众包库字段 | `g` 有无；`gs` σ；`grat` Hz；`gn` 芯片名 |
| 接入状态 | 仅对照，未改实验 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

绕本体轴的角速度。理想静止：三轴 ~0，σ 反映零偏和噪声。  
\(360^\circ/\mathrm{s} = 2\pi \approx 6.28\,\mathrm{rad/s}\)。若静止就到几 rad/s，或转一圈积分差很多，再查单位（有的 HAL 用 °/s）。

## 2. 代码路径

`SensorInput` → `TYPE_GYROSCOPE`。无校准/未校准切换（Android 另有 `TYPE_GYROSCOPE_UNCALIBRATED`，传感器页能看到，实验不切）。  
库基线：`σ` + Hz + 芯片名，没有 rest 均值（静止本应接近 0）。

## 3. 内置实验

`gyroscope.phyphox`，`pendulum.phyphox`（50 Hz），`roll.phyphox`（25 Hz 平均），`centripetal_acceleration.phyphox`。

## 4. 已知坑

- 零偏：静置几秒仍有常值偏移，积分角度会漂。
- 采样率虚标：单摆要够的 Hz，以 `SampleWindow` 实测为准。
- 单位：°/s 对 rad/s 会差 \(180/\pi \approx 57.3\) 倍，比加速度的 9.8 更好认。
- 未校准变体带漂移估计，实验尚未提供切换。

## 5. 现行做法

实验原样。传感器页显示 σ、Hz、库基线。

## 6. 候选规则（草案）

1. 静止 2 s，若 \|ω\| 均值在 50–70（像 °/s 的地球转速？不，地球太小）——更现实：对已知转台或「转一圈看积分」。
2. 第一版不做自动乘  π/180，只在详情页标「疑似 °/s」并给开关。
3. 零偏：可选静止校准（减均值），必须可重置，不能当默认暗扣。

## 7. 待测机型与问题

- [ ] 静置 σ 与库 `gs` 比
- [ ] 手转约 180°，积分是否接近 π
- [ ] 单摆实验在低采样机上是否明显失真
