# 姿态

| 项 | 值 |
|---|---|
| 实验类型名 | `attitude` |
| Android type | `Sensor.TYPE_ROTATION_VECTOR`（值为 11） |
| SI 单位 | 无（四元数分量，无量纲） |
| 分量 | x y z（向量部分）；`abs` 在源码里按 \(w\) 估 |
| 众包库字段 | 无 |
| 接入状态 | 代码认，内置实验几乎不用 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

旋转矢量：`values[0..2]` 为四元数 x/y/z，\(w\) 可从归一化推出。不是欧拉角度数。游戏旋转矢量（无磁力）传感器页可能另列一项。

## 2. 代码路径

`SensorInput` → `TYPE_ROTATION_VECTOR`。`appendToBuffers` 对这个 type 的 abs 用 `sqrt(aquisitions² - x² - y² - z²) / aquisitions` 估 w，和其他传感器的模长公式不同。

## 3. 内置实验

无 `type="attitude"`。倾角实验用的是加速度计，不是旋转矢量。

## 4. 已知坑

融合依赖磁力计/陀螺，室内磁场差时航向会漂。单位不是「精度校正」问题，是融合质量问题。

## 5. 现行做法

原样。无库对照。

## 6. 候选规则（草案）

不乘系数。若以后做姿态实验，单独谈坐标系和航向可靠性。
