# 重力

| 项 | 值 |
|---|---|
| 实验类型名 | `gravity` |
| Android type | `Sensor.TYPE_GRAVITY`（值为 9） |
| SI 单位 | m/s² |
| 分量 | x y z + abs |
| 众包库字段 | 无 |
| 接入状态 | 代码认，内置实验几乎不用 |
| 研究状态 | 待研究（跟加速度计） |

## 1. 物理量与期望值

多数机不是独立芯片，而是从硬件加速度计**合成**：对 \(\mathbf{a}\) 做低通或和陀螺融合，得到慢变的 \(\mathbf{g}\)。静止时模长应 ≈ \(g\)，方向随姿态变。和加速度计单位必须一致。

怎么估计、凭什么拆，见 `02-linear-acceleration.md` §1.1。重力传感器输出的就是那里的 \(\hat{\mathbf{g}}\)，不是芯片另测的场。

## 2. 代码路径

`SensorInput.SensorName.gravity`。`SensorCatalog` 有标题和单位。无库基线。内置 `.phyphox` 未检索到 `<sensor type="gravity">`。

## 3. 内置实验

无。自定义实验仍可声明。

## 4. 已知坑

与线性加速度成对：加速度 ≈ 线性 + 重力。一边乘 \(g_0\) 另一边不乘会自相矛盾。

## 5. 现行做法

原样。传感器页能看到（若 HAL 提供）。

## 6. 候选规则（草案）

加速度计单位开关应同时作用于此 type。

## 7. 待测机型与问题

- [ ] HAL 是否单独提供 TYPE_GRAVITY
- [ ] 静止 \|g\| 是否与加速度计模长一致
