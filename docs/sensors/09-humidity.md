# 湿度

| 项 | 值 |
|---|---|
| 实验类型名 | `humidity` |
| Android type | `Sensor.TYPE_RELATIVE_HUMIDITY`（值为 12） |
| SI 单位 | % |
| 分量 | 标量 |
| 众包库字段 | `h` 仅有/无 |
| 接入状态 | 仅对照，未改实验 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

相对湿度 0–100。室内常见 20–80。手机几乎没有这颗传感器。

## 2. 代码路径

标准 type 缺失时，扫私有传感器、名字含 `humidity`，并标 vendor。

## 3. 内置实验

仅 `sensordb.phyphox`。外接见 Sensirion / TI SensorTag 等蓝牙实验。

## 4. 已知坑

基本是「没有」。误匹配的 vendor 传感器不可信。

## 5. 现行做法

原样；没有就不做实验。不编造湿度。

## 6. 候选规则（草案）

不校正。需要湿度就走蓝牙。

- [ ] 确认目标机型均无标准湿度计即可结案
