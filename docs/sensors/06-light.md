# 光照

| 项 | 值 |
|---|---|
| 实验类型名 | `light` |
| Android type | `Sensor.TYPE_LIGHT`（值为 5） |
| SI 单位 | lx |
| 分量 | 标量（有的 HAL 多通道，实验只用 values[0]） |
| 众包库字段 | `li` 仅有/无 |
| 接入状态 | 仅对照，未改实验 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

室内灯光大约 50–500 lx，阴天室外约 10³–10⁴，晴天可达 10⁵。  
光学秒表看的是**相对跳变**，绝对校准不是第一优先。

## 2. 代码路径

`SensorInput` → `TYPE_LIGHT`。多为 on-change：光线不变时可能长时间无事件，`rateStrategy=generate` 会补点。时间戳偏移也多见于这类传感器。

## 3. 内置实验

`light.phyphox`，`optical_stopwatch.phyphox`，蓝牙 HID Mouse Light。

## 4. 已知坑

- 量程被 OEM 砍到自动亮度够用为止（例如封顶 1000 lx），实验「照度」不准。
- 红外截止/开孔位置导致和真实 lux 差一个系数。
- 部分机只有几档离散值。
- 库没有典型 lux，无法对照绝对值。

## 5. 现行做法

实验原样。基线文案只有「库：有/无光照传感器」。详情页展示自称量程。

## 6. 候选规则（草案）

不做全局 lux 校准。光学秒表保持相对阈值。若要绝对照度，另做「用户用已知灯具标定」而不是猜 HAL 系数。
