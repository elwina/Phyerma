# 温度

| 项 | 值 |
|---|---|
| 实验类型名 | `temperature` |
| Android type | `Sensor.TYPE_AMBIENT_TEMPERATURE`（值为 13） |
| SI 单位 | °C |
| 分量 | 标量 |
| 众包库字段 | `t` 仅有/无 |
| 接入状态 | 仅对照，未改实验 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

环境温度应接近室温（约 15–35 °C）。电池/AP 温度常在 30–50 °C 且随充电上升，**不是**环境温度。

## 2. 代码路径

标准 type 没有时，扫私有传感器，名字含 `temperature` 或 `thermo`。源码注释：三星 `thermistor` 往往读不到数，不要轻易当可用。命中则 `vendorSensor = true` 并警告。

## 3. 内置实验

只有 `sensordb.phyphox`（`ignoreUnavailable`）。没有面向课堂的温度实验。蓝牙外设另算。

## 4. 已知坑

- 手机几乎不带环境温度计。
- vendor 回退容易接到电池 NTC。
- 单位偶见开尔文（~300）。

## 5. 现行做法

实验原样 + vendor 警告。无数值库基线。

## 6. 候选规则（草案）

读数在 270–330 且几乎不随「吹气/离开空调」变：提示疑似 K 或芯片温度。默认不把电池温度当环境温度展示给学生。课堂测温走蓝牙探头（`16`）。
