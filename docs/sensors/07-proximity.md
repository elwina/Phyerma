# 距离传感器

| 项 | 值 |
|---|---|
| 实验类型名 | `proximity` |
| Android type | `Sensor.TYPE_PROXIMITY`（值为 8） |
| SI 单位 | cm（文档如此；多数机不是真厘米） |
| 分量 | 标量 |
| 众包库字段 | `pr` 仅有/无 |
| 接入状态 | 仅对照，未改实验 |
| 研究状态 | 待研究 |

## 1. 物理量与期望值

Android 允许「远」报 `getMaximumRange()`，「近」报一个更小值。大量手机只有这两档，不能当超声测距。

## 2. 代码路径

`SensorInput` → `TYPE_PROXIMITY`。典型 on-change，时间戳和 `generate` 策略与光照同类。

## 3. 内置实验

`proximity_stopwatch.phyphox`（靠遮挡边沿计时，不靠绝对 cm）。

## 4. 已知坑

- 听筒旁红外，不是 ToF 测距（ToF 见 `15-depth.md`）。
- 全面屏下的虚拟距离 / 厂商私有 type，标准 `TYPE_PROXIMITY` 可能缺失或恒远。
- 单位写 cm 会误导学生。

## 5. 现行做法

实验原样。无库数值基线。传感器页按 cm 显示原始值。

## 6. 候选规则（草案）

详情页若取值集合只有 2 个，标明「二元近/远，不是连续距离」。不把值换算成真 cm。秒表实验继续用边沿。
